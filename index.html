1. Web Architecture Concepts

Client-Server Model

The Client(your browser) sends a request, and the Server returns the web page response.

DNS (Domain Name System)

Translate the human-friendly domain name (like example.com) into numeric IP Addresses.

HTTP vs. HTTPS

HTTP sends data in plain text, while HTTPS encrypts data security using SSL/TLS.
